# Drive-3D
# 🏎️ NEON DRIVE 3D

Three.js 기반의 웹 브라우저용 3D 아케이드 사이버 드라이빙 게임입니다.  
별도의 설치 없이 PC와 모바일 웹 브라우저에서 바로 플레이할 수 있습니다.

🔗 **플레이 링크:** [https://hannaj1763-sketch.github.io/drive-3d/](https://hannaj1763-sketch.github.io/drive-3d/)  
🎨 **메인 갤러리:** [https://hannaj1763-sketch.github.io/gallery2026/](https://hannaj1763-sketch.github.io/gallery2026/)

---

## 🎮 조작 방법

### PC (키보드)
* **좌 / 우 이동:** `◀` `▶` 방향키 또는 `A` / `D`
* **부스터 가속:** `▲` 방향키, `W`, 또는 `Space` (누르고 있는 동안 속도 및 점수 획득량 증가)

### 모바일 (터치)
* **좌 / 우 이동:** 화면 하단 좌측 `◀` `▶` 버튼 터치
* **부스터 가속:** 화면 하단 우측 `BOOST` 버튼 홀드

---

## 🛠️ 기술 스택
* **HTML5 / CSS3 / Vanilla JavaScript**
* **Three.js (r128)** - 3D 렌더링, 안개(Fog) 효과, 동적 시야각(FOV) 제어
